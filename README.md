<br>

## ⚡ What I do

### 🧊 PowerNukkitX

I'm a developer on [PowerNukkitX](https://github.com/PowerNukkitX/PowerNukkitX), an open-source Minecraft: Bedrock Edition server written in Java.

My work includes world generation, biomes, structures, and game mechanics, as well as compatibility fixes and performance improvements. I enjoy getting into the details of how Minecraft works and bringing that behavior to the server.

### 📦 Plugins

On **PowerNukkitX-Bundle**, I work on plugins that everyone could need.

It's where I turn ideas into features that players and server owners can use, building on the ecosystem I help develop.
